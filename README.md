# Customer Churn Analysis

## Overview

A beginner-level data analytics project using Python and Pandas to analyze customer churn patterns.

## Objectives

- Calculate customer churn rate
- Analyze churn by contract type
- Analyze churn by customer tenure
- Compare monthly charges
- Analyze customer support interactions
- Generate business insights

## Technologies

- Python
- Pandas
- Matplotlib
- CSV

## Analysis Performed

- Data inspection
- Missing-value analysis
- Churn-rate calculation
- Customer segmentation
- Contract-based churn analysis
- Tenure-based churn analysis
- Basic visualization

## Key Insights

The analysis identifies customer characteristics associated with higher churn and demonstrates how customer data can support retention strategies.

## How to Run

```bash
pip install -r requirements.txt
python churn_analysis.py
